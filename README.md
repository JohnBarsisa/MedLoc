# MedLoc — Online Pharmacy Website Concept

A responsive **front-end prototype** for an online pharmacy storefront. The current repository consists of a self-contained `index.html` and demonstrates product presentation, navigation, marketing sections and a pharmacy-oriented visual style.

## The concept

MedLoc imagines a pharmacy shopping experience in which visitors can discover categories, browse promoted products, explore health content and eventually access secure ordering and delivery.

## Current source

- HTML with inline styling and page sections
- Bootstrap 5, Font Awesome and Google Fonts loaded from CDNs
- External stock imagery for placeholder products and banners
- Responsive landing-page layout

## View the page

Open `index.html` locally in a modern browser, or run:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`. CDN connectivity is needed for the intended typography and styling.

## Important scope clarification

This repository is **a visual concept, not a licensed pharmacy or functioning e-commerce platform**. Catalogue items, prices, partner logos, addresses, app-store badges and card-network imagery are mock/illustrative page content. They do not establish real partnerships, medical advice, product availability, dispensing authorisation or payment integrations.
